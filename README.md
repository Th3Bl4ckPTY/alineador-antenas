# Alineador de Antenas - App Android

## Cómo obtener el APK (gratis, sin instalar nada)

### 1. Subí el proyecto a GitHub
- Creá una cuenta en github.com (gratis)
- Creá un repositorio nuevo (público o privado)
- Subí todos los archivos de esta carpeta

### 2. GitHub Actions compila el APK automáticamente
- Andá a la pestaña **Actions** de tu repositorio
- Verás el workflow "Build APK" ejecutándose
- Esperá ~5 minutos

### 3. Descargá el APK
- Al terminar, hacé clic en el workflow completado
- Bajá al final y descargá **alineador-antenas-apk**
- Descomprimí el ZIP y vas a tener el archivo `app-debug.apk`

### 4. Instalá en Android
- Enviá el APK al teléfono (WhatsApp, email, Drive)
- Activá "Instalar desde fuentes desconocidas" si te lo pide
- Instalá normalmente
